# Lily Pad Math website

Public pages for the Lily Pad Math app:

- **Home:** https://lilypadmathapp.github.io/lily-pad-math-site/ (App Store landing page)
- **Privacy policy:** https://lilypadmathapp.github.io/lily-pad-math-site/privacy.html
- **Support:** https://lilypadmathapp.github.io/lily-pad-math-site/support.html

The privacy and support URLs are listed in App Store Connect, so keep those two paths working.
`privacy.html` and `support.html` are copied from the private `lily-pad-math` repo, so edit them there first.

The web version of the game has been retired. `sw.js` is a cleanup worker that removes the offline copy
from devices that installed it; leave it in place.
